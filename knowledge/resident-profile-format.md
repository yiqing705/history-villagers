# 居民人物檔案格式（第一版）

居民資料要同時支援角色扮演、學科連結與可辨識的 Q 版造型。每個檔案分開記錄可查證的人物資料、造型參考和創作對話；尚未驗證的內容要明確標成提案。

## 欄位

| 欄位 | 必填 | 用途 |
| --- | --- | --- |
| `id` / `name` | 是 | 穩定識別碼與居民顯示姓名。 |
| `domains` | 是 | 對應歷史、十五篇古文或自然科學科目。 |
| `curriculumLinks` | 是 | 對應學測範圍、課文或概念；審核完成前標示為待確認。 |
| `verifiedFacts` | 是 | 有可靠資料支持的簡要生平、作品或科學貢獻，逐項附來源。 |
| `visualReferences` | 是 | Q 版造型可參考的肖像、文物、服飾或象徵物，註明來源、年代與限制。 |
| `designBrief` | 是 | 可交給美術製作的辨識元素、比例、表情和服裝提案。明確區分歷史圖像詮釋與本人真實外貌。 |
| `voice` | 是 | 角色的說話節奏、用字和情緒基調，避免僅用刻板印象扮演人物。 |
| `fictionalDialogue` | 是 | 遊戲創作對話；不得誤標為歷史原文或人物真實言論。 |
| `reviewStatus` | 是 | `提案`、`待審`、`已審`，表示內容目前的查核程度。 |

## 蘇軾（示範提案）

- `id`: `su-shi`
- `domains`: 歷史、國文古文
- `curriculumLinks`: 可能連結宋代歷史與十五篇古文相關課文；首發課文範圍待確認。
- `verifiedFacts`: 國立故宮博物院典藏資料記載蘇軾字子瞻、號東坡（部分資料作東坡居士），為北宋文學家、政治家與書法家。依採用的館藏條目逐條標註資料來源。
- `visualReferences`: 國立歷史博物館典藏的蘇軾畫像資料描述其形象為紗冠、白袍、竹杖，並指出造型近似趙孟頫所繪《東坡小像》。這是後世繪畫的文化形象，不能視為蘇軾生前外貌照片或唯一可信肖像。
- `designBrief`: Q 版比例；以紗冠、寬袖袍與竹杖作為可辨識的圖像符號，配色和表情可親。需保留「後世肖像詮釋」的說明，不添加未有依據的生理特徵。
- `voice`: 待角色設計；可親、好奇、帶文人氣息的創作方向，避免把虛構口頭禪冒充原文。
- `fictionalDialogue`: 「今天風不錯，要不要陪我去海邊走走？」（遊戲創作句，不是蘇軾原話。）
- `reviewStatus`: 提案；範圍連結、學科內容及正式造型尚待審核。

## 參考資料

- [國立故宮博物院：宋四家集冊・宋蘇軾書跋語](https://digitalarchive.npm.gov.tw/Collection/Detail/958?dep=P) — 蘇軾生平與身分資料。
- [文化部典藏網：蘇軾畫像](https://collections.culture.tw/Object?RNO=NzQtMDA4OTg%3D&SYSUID=14) — 後世典藏畫像的造型描述與畫作脈絡。

以上來源用於示範人物檔案如何標註資料與限制；實際使用館藏圖像前仍須遵循館方授權及姓名標示規範。本檔案不代表首批居民名單已定案。
