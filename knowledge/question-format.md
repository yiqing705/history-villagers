# 題目內容格式（第一版）

此格式用於拾史島的單題選擇題原型，涵蓋出題、作答回饋與來源追溯。題庫資料應與互動介面分開，讓題目可新增、校訂或轉換儲存方式，而不用重寫答題流程。

## 欄位

| 欄位 | 必填 | 用途 |
| --- | --- | --- |
| `id` | 是 | 穩定且唯一的題目識別碼。 |
| `resident` | 是 | 提問居民名稱。 |
| `subject` | 是 | 學科名稱，例如歷史、國文、物理、化學、生物、地球科學。 |
| `source.type` | 是 | `歷屆試題`、`自編練習題` 或 `自編示範題`；不把自編內容誤標為考古題。 |
| `source.reference` | 是 | 歷屆題填年份、考試與題號等可追溯資訊；自編題沒有外部來源時用 `null`。 |
| `scope` | 是 | 課綱／學測範圍內的分類標籤，應能指出內容邊界。 |
| `keyPoint` | 是 | 題目測量的核心概念。 |
| `stem` | 是 | 題幹。 |
| `options` | 是 | 以穩定代碼對應選項文字；數量依題型，單選題應只有一個正確選項。 |
| `answer` | 是 | `options` 中唯一正確的代碼。 |
| `distractors` | 是 | 每個錯誤選項各自對應的常見誤解或解題提示，協助針對性教學。 |
| `solution` | 是 | 正確解題思路與答案依據，錯答後提供。 |
| `extension` | 是 | 答對後的延伸知識；保持相關、簡短且在學測範圍內。 |

## 來源和審核狀態

- `source.reference` 可是一個可回查來源，也可用陣列列出多個來源；每個連結應支持該題的事實或教學脈絡。純自編且無外部事實依據的示範題可填 `null`，但「自編」不等於免除正確性審查。
- 候選題庫另加 `reviewStatus` 記錄 `提案／待審` 或 `已審核`。只有經相應領域確認範圍、唯一答案、干擾選項、解析、延伸與來源後，才能進入正式題庫；資料欄位齊全不表示內容已核准。
- 正式使用歷屆試題前，除了年份、考科和題號，還需確認題幹與選項的引用授權；自編題需能追溯支撐事實和範圍判斷的資料。

## 回饋規則

- 作答前不顯示正解、選項判斷或解析。
- 答錯：先回應所選錯誤選項的迷思並提供考點／題幹線索；玩家可選擇展開完整解析，查看正解和解題思路。
- 答對：肯定作答，說明判斷依據，延伸一個可連結的知識點。
- 重新作答會清空本題狀態，不改變題目資料。
- 示範或自編題清楚標示來源類型；加入真實歷屆題前，另確認引用資訊與使用權限。

## 範例

目前首頁與 3D 島嶼共用的單題示範物件在 [`question-data.js`](../question-data.js)。它展示最小必要資料與回饋流程，尚非通過學科審查的正式題庫。正式匯入前須由熟悉該科內容的人員確認範圍、答案、解析與來源。
